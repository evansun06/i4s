The log is an EventBus (src/core/events.ts). Each Orchestrator creates one and exposes it as orchestrator.bus, but you can also 
create one on its own.                                                                                                          
Creating one

import { EventBus } from './core/events.js';

// On its own, e.g. for tests or replaying a saved session
const bus = new EventBus();

// The orchestrator's own log, which the agents read
const bus = orchestrator.bus;

Use orchestrator.bus for the live discussion. A separate new
EventBus() starts empty, and the orchestrator never sees what you add to it.
